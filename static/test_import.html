❓ 常见问题

Q1: 点击"开始导入"没反应？

可能原因：

  • 没有选择CSV文件 → 会弹出提示"请先选择CSV文件"
  • JavaScript错误 → 查看控制台是否有红色错误
  • 按钮事件未绑定 → 刷新页面重试
Q2: 还是很慢？

检查步骤：

  1. 查看控制台日志，找到"准备调用API..."这行
  2. 如果这行之前就很慢 → CSV解析问题（数据太大？）
  3. 如果这行之后才慢 → 服务端问题（需要优化数据库）
  4. 记录具体耗时，提供给我分析
Q3: 数据还是重复？

验证方法：

  1. 点击导入后，立即多次快速点击按钮
  2. 应该看到alert提示"正在导入中，请稍候..."
  3. 如果没有这个提示，说明代码没更新成功
  4. 检查数据库：sqlite3 salary.db "SELECT COUNT(*) FROM field_linkage;"
